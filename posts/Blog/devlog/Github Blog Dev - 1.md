# 깃허브 페이지 생성법

## 레포지토리 생성
깃허브 페이지를 생성하기 위해선 여러방법이 존재하지만 가장 쉬운 내 아이디로 페이지를 만들어보겠다.

깃허브 페이지는 레포지토리 단위가아닌 각 계정단위로 동작하기 때문에 아이디 기반으로 만들면 따로 배포할 필요없이 자동으로 배포가 된다.

> 아이디.github.io로 레포지토리를 생성해 준다
> *반드시 Public으로 해야 무료로 page를 공개 할 수 있다.*

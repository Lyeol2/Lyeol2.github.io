# Project Goal

제목 : 원샷
장르 : 2D 로그라이크
키워드 : 중세, RPG

 도트비주얼의 게임
640x480 해상도를 가지고있으며
임시그래픽 생성시 픽셀아트를 생성합니다



## 스토리
당신은 중세판타지에 떨어진 일반인입니다. 최대한 오래 살아남으십시오

## 화면 구성
1. 전체화면은 현재있는 맵의 1인칭 시점이 그려집니다.
2. 우측 상단에는 항상 그리드 형태의 지도가 떠있습니다
3. 중하단에는 현재 상황을 설명하는 채팅창과 현재 캐릭터 상태를 보여줍니다.


## 시스템

### 1. 맵생성 시스템
NxN 그리드 맵을 절차적으로 생성함
그 후 캐릭터 1인칭 시점으로 맵을 돌아다닐 수 있음 

### 2. 점수시스템
업적점수라는게 있음 이게 게임의 전체 스코어를 말해
얻는 방법은 다음과 같아
1. 적 또는 몬스터를 처치한다
2. 시민들에게 호감도를 얻는다

### 3. 스탯
플레이어에게는 하단의 스탯을 가지고있음

돈 : 500
레벨 : 1
경험치 : 0
체력 : 20
마나 : 10
공격력 : 10
방어력 : 10
지능 : 10

레벨업시 체력 마나 공격력 방어력 지능중 스탯하나를 찍을 수 있음

### 4. 전투

게임은 턴제전투로 진행되며 포켓몬스터 시스템을 참고합니다

기사

- 레벨 15 이상
- 
마법사

- 레벨 15이상
